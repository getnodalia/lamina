Lámina habla español: toda la interfaz se puede usar en español, y las preferencias están ahora en la página Archivo.
*Lámina speaks Spanish: the whole interface can be used in Spanish, and preferences now live on the File page.*

## Español

### Novedades
- **Interfaz en español:** botones, menús, cinta, diálogos, paneles, menús contextuales y la barra de estado se muestran en español, no solo las pestañas de la cinta.
- **Idioma:** se elige en las preferencias; si no eliges ninguno, Lámina usa el idioma del sistema.
- **Preferencias en Archivo:** las preferencias se abren dentro de la página Archivo, como el resto de opciones del documento.

## English

### What's new
- **Spanish interface:** buttons, menus, the ribbon, dialogs, panels, context menus and the status bar show in Spanish, not just the ribbon tabs.
- **Language:** pick it in preferences; with none picked, Lámina follows the system language.
- **Preferences on the File page:** preferences open inside the File page, alongside the document's other options.
