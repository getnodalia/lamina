Lámina 0.4.0 dibuja imágenes SVG, crea gráficos desde una hoja de cálculo, imprime directamente y suma seis plantillas de inicio nuevas.
*Lámina 0.4.0 draws SVG pictures, builds charts from a spreadsheet, prints straight to the printer and adds six new starter decks.*

## Español

### Novedades
- **Imágenes SVG:** los iconos y logotipos en SVG (y SVGZ) ya se ven. Insertar ▸ Imagen acepta archivos `.svg`, se dibujan nítidos a cualquier tamaño y conservan los recortes, el mosaico y el cambio de color como cualquier otra imagen. Los iconos de PowerPoint se dibujan desde su SVG y se guardan junto con su PNG de respaldo, así que el archivo sigue abriéndose en otros programas. Los archivos hostiles o demasiado pesados se rechazan sin cerrar la aplicación.
- **Gráfico desde una hoja de cálculo:** Insertar ▸ Gráfico ▸ Desde hoja de cálculo… lee un rango de un libro `.xlsx`, `.xlsm`, `.xlsb` o de un archivo `.csv`/`.tsv`, detecta solo si la primera fila y la primera columna son títulos y construye el gráfico. «Actualizar desde el origen» (Diseño de gráfico ▸ Datos) vuelve a leer el archivo y conserva el formato de cada serie.
- **Imprimir de verdad:** Archivo ▸ Imprimir envía diapositivas, folletos o páginas de notas directamente a la impresora elegida, con intervalo de páginas, copias y doble cara. Si no hay una cola de impresión disponible, se abre el PDF como antes.
- **Seis plantillas nuevas, en español e inglés:** Retrospectiva, Balance del año, Nota de decisión, Guía paso a paso, Portafolio y Plan de lanzamiento, con las diapositivas ya escritas y notas del orador, en temas tranquilos.
- Órdenes nuevas para la línea de comandos, el canal de control y MCP: `insert.chart.fromSheet`, `chart.refreshFromSource`, `file.printers` y `file.print`.

### Notas
- Un SVG con texto lo dibuja solo si el archivo ya lo convirtió en trazados; Lámina no sustituye tipografías que no tiene.
- No se imprime el esquema, y la impresión directa no abre el cuadro de diálogo del sistema; el visor de PDF sigue disponible para eso.

## English

### What's new
- **SVG pictures:** SVG and SVGZ icons and logos now show. Insert ▸ Picture accepts `.svg` files, they are drawn sharp at any size and keep their crop, tiling and recolouring like any other picture. PowerPoint's icons are drawn from their SVG and saved together with their PNG fallback, so the file still opens in other programs. Hostile or oversized files are refused without closing the app.
- **Chart from a spreadsheet:** Insert ▸ Chart ▸ From Spreadsheet… reads a range from an `.xlsx`, `.xlsm` or `.xlsb` workbook or a `.csv`/`.tsv` file, detects whether the first row and column are labels and builds the chart. Update from Source (Chart Design ▸ Data) reads the file again and keeps each series' formatting.
- **Real printing:** File ▸ Print sends slides, handouts or notes pages straight to the chosen printer, with a page range, copies and two-sided. Where no print queue is available, the PDF opens as before.
- **Six new starter decks, in English and Spanish:** Retrospective, Year in Review, Decision Brief, How-To Guide, Portfolio and Launch Plan, with the slides already written and speaker notes, on calm themes.
- New commands for the command line, the control channel and MCP: `insert.chart.fromSheet`, `chart.refreshFromSource`, `file.printers` and `file.print`.

### Notes
- Text in an SVG is drawn only when the file has already turned it into paths; Lámina does not substitute fonts it doesn't have.
- The outline can't be printed yet, and direct printing doesn't open the system's print dialog; the PDF viewer is still there for that.
